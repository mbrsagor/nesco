# Shopkeeper Frontend

The project is a basically multi vendor online shop management system (Frontend) web application which all shop will manage own business. Every single shop can product add, update, sales etc. 

#### Setup

> Install the project in your system:

###### please follow the below instructions
```bash
git clone https://github.com/mbrsagor/shopkeeper-admin.git
cd shopkeeper-admin
yarn install
yarn start
```

Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
